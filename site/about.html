Цель проекта

Создать Telegram-бота для транспортной компании, который помогает фиксировать рабочее время сотрудников и анализировать эффективность труда.

Основные задачи

  • Учёт времени отдыха.
  • Учёт отвлекающих факторов.
  • Учёт дополнительных рабочих задач.
  • Экспорт статистики.
  • Уведомления и напоминания.
  • Ежедневный отчёт для руководителя.

Технологии

Python, aiogram, Git, GitHub, HTML, CSS, Markdown.

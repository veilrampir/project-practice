## Задание
Задание размещено в папке `task` в файле `README.md`.


Разработка Telegram-бота для транспортной компании с функциями:
- фиксация времени отдыха сотрудников;
- учёт времени на отвлекающие факторы;
- учёт времени на дополнительные рабочие задачи;
- уведомления и ежедневные отчёты для руководителя.  

Дополнительные источники:  
- [Telegram Bot API](https://core.telegram.org/bots/api)  
- [aiogram документация](https://docs.aiogram.dev/)
